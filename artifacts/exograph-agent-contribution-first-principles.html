Exograph · first principles of agent-first software

Good agent contributions are designed into the repository.

A capable model can still make a bad change. Exograph improves the odds by making the right context easy to find, the safe path easier to follow, the real outcome possible to prove, and each lesson harder to forget.

The causal argument

Why each layer exists, derived from the failure it prevents.

01Output is a proposal, not truth.

Therefore: every change must terminate in evidence and review, not model confidence.

02Context determines the search space.

Therefore: root guidance routes to the smallest authoritative owner and names what that owner must not do.

03Architecture is executable guidance.

Therefore: deep modules, typed seams, closed protocols, and authority boundaries constrain where a valid change can live.

04Feedback must arrive while it can steer.

Therefore: narrow owner tests run first; the broad gate and Electron or packaged journeys follow at the claim boundary.

05Proof and permission are different.

Therefore: CI establishes a candidate’s technical credibility; only the release path and human maintainer grant promotion.

06Memory does not compound reliably.

Therefore: recurring lessons become the smallest durable ratchet: a type, test, module boundary, workflow check, or owner guide.

What remains deliberately unclaimed

Passing machinery is necessary, but it is not the same as a finished trust system.

  • No genuine packaged-first-run agent job yet. The candidate workflow tests packaged onboarding, but whole-job agent qualification for that class remains open.
  • CI is not yet a required merge block. Protected main remains a GitHub settings and human-authority gate.
  • No signed public release proof yet. Signing, notarization, clean-install, rollback, and final SBOM/package-content evidence remain explicit release work.
  • Human judgment is not automated away. Product direction, diff acceptance, visual quality, accessibility judgment, and promotion stay with the maintainer.
The boundary that matters: Exograph-the-product does not make the external agent intelligent. It makes the repository legible, the safe change path narrow, the feedback timely, the evidence honest, and promotion controlled.
